## Cerințe de sistem

- **Python** 3.10 sau mai nou.
- **Pachete Python**: `torch`, `transformers` și `accelerate` (folosit pentru plasarea automată a modelului pe placa grafică).
- **Spațiu pe disc**: modelul SmolLM2-360M-Instruct, folosit în primele pagini, ocupă aproximativ 700 MB. Modelul Qwen3-1.7B, de pe ultima pagină, ocupă aproximativ 4 GB.
- **Hardware**: orice calculator cu cel puțin 8 GB de memorie RAM. O placă grafică NVIDIA (CUDA) sau un cip Apple Silicon (MPS) face generarea mult mai rapidă, dar modelele mici rulează și pe procesor (CPU).

## Instalare

Pentru a crea un mediu virtual și a instala pachetele, rulați comenzile de mai jos:

```bash

python3 -m venv .venv
source .venv/bin/activate
pip install torch transformers accelerate
```

Pe Linux și Windows, varianta de PyTorch potrivită pentru placa grafică se alege de pe [pagina de instalare PyTorch](https://pytorch.org/get-started/locally/). Alte metode de instalare a bibliotecii Transformers sunt descrise în [ghidul de instalare](https://huggingface.co/docs/transformers/installation).

## Primul model

Cel mai scurt drum de la nimic la un răspuns este funcția `pipeline`, care ascunde toți pașii intermediari. Salvați codul de mai jos în fișierul `primul_model.py`:

```python
from transformers import pipeline

# La prima rulare, fișierele modelului (aproximativ 700 MB) se descarcă de pe Hugging Face Hub.
generator = pipeline("text-generation", model="HuggingFaceTB/SmolLM2-360M-Instruct")

messages = [{"role": "user", "content": "What is the capital of France? Answer in one sentence."}]
result = generator(messages, max_new_tokens=40)
print(result[0]["generated_text"][-1]["content"])
```

Apoi rulați:

```bash
python primul_model.py
```

```text
The capital of France is Paris.
```

[SmolLM2-360M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-360M-Instruct) este un model mic, cu 362 de milioane de parametri, publicat de Hugging Face sub licența Apache 2.0. A fost antrenat în principal pe text în engleză, așa că îi scriem în engleză. Răspunde rapid chiar și pe un laptop, dar greșește des, după cum vom vedea pe pagina următoare.

Funcția `pipeline` poate face mult mai mult decât generare de text, de exemplu clasificare, traducere sau recunoașterea vorbirii. Sarcinile disponibile sunt descrise în [ghidul despre pipeline](https://huggingface.co/docs/transformers/pipeline_tutorial).

## Unde ajung fișierele modelului

La prima rulare, Transformers descarcă ponderile, configurația și tokenizatorul în directorul `~/.cache/huggingface/hub`. La rulările următoare, fișierele sunt citite de acolo, fără conexiune la internet. Directorul poate fi mutat cu variabila de mediu `HF_HOME`, iar modelele descărcate pot fi listate și șterse cu comanda `hf cache`. Toate opțiunile sunt descrise în [ghidul despre memoria cache](https://huggingface.co/docs/huggingface_hub/guides/manage-cache).

:::note[Modele cu acces restricționat]
Unele modele, de exemplu cele din familia Llama, pot fi descărcate doar după acceptarea licenței pe pagina modelului și după autentificare, cu comanda `hf auth login`. Pașii sunt descriși în [documentația despre modelele cu acces restricționat](https://huggingface.co/docs/hub/models-gated). Modelele folosite în acest laborator nu au nevoie de autentificare.
:::

## Alegerea unui model

Pe [Hugging Face Hub](https://huggingface.co/models), modelele pot fi filtrate după sarcină (pentru conversație, _Text Generation_), după licență și după mărime. **Pagina fiecărui model** (_model card_) spune pentru ce a fost antrenat, ce limbi cunoaște, sub ce licență poate fi folosit și, de obicei, ce parametri de generare recomandă autorii. Merită citită înainte de a folosi modelul.

Pentru început, sunt potrivite modelele mici, cu sub 2 miliarde de parametri, care încap ușor în memorie. Codul din laborator funcționează la fel pentru modele mai mari. Se schimbă doar numele modelului și, după cum arată pagina despre [memorie](/laboratoare/model-local-transformers/memorie-si-dispozitive/), cantitatea de memorie necesară.
