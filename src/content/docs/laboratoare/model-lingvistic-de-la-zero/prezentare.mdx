Modelul se numește **mvGPT** (_Minimum Viable GPT_) și este o implementare minimală, dar complet funcțională, a unui model de tip GPT. Are 14,6 milioane de parametri (de aproximativ 12.000 de ori mai puțini decât GPT-3) și se antrenează în circa zece minute pe un laptop modern. Codul, scris în Python și PyTorch, este împărțit în șapte fișiere, pe care le explicăm integral pe parcursul laboratorului.

Laboratorul urmărește primele trei episoade ale seriei video [Minimum Viable GPT](https://mvgpt.nenuadrian.com) și le însoțește cu explicații în limba română. Codul complet, cu comentarii tot în română, se află pe GitHub, în repozitoriul [**inteligentArtificiala-ro/laborator-lm-de-la-zero**](https://github.com/inteligentArtificiala-ro/laborator-lm-de-la-zero).

Un proiect asemănător, dar mai amplu, este [nanochat](https://github.com/karpathy/nanochat), scris de Andrej Karpathy. Cu un cod minimal, ușor de citit și de modificat, nanochat parcurge tot drumul până la un asistent conversațional: tokenizatorul, preantrenarea, ajustarea fină supervizată, învățarea prin consolidare, evaluarea și o interfață de chat. Este gândit în principal pentru un server cu 8 plăci grafice H100. Pe un laptop se poate antrena doar o variantă mult mai mică.

## Etapele laboratorului

<Steps>
1. [**Datele și tokenizarea**](/laboratoare/model-lingvistic-de-la-zero/date-si-tokenizare/) prezintă setul de date TinyStories, un tokenizator la nivel de cuvânt și felul în care poveștile devin șiruri de numere.
2. [**Modelul GPT**](/laboratoare/model-lingvistic-de-la-zero/modelul-gpt/) construiește, clasă cu clasă, un Transformer doar cu decodor și îi numără parametrii.
3. [**Preantrenarea**](/laboratoare/model-lingvistic-de-la-zero/preantrenare/) explică predicția următorului token, loturile de antrenare, optimizatorul AdamW, rata de învățare și procesul de antrenare.
4. [**Generarea textului**](/laboratoare/model-lingvistic-de-la-zero/generarea-textului/) arată eșantionarea autoregresivă, cu temperatură și filtrare top-k.
5. [**Ajustarea fină supervizată**](/laboratoare/model-lingvistic-de-la-zero/ajustare-fina-supervizata/) învață modelul să urmeze instrucțiuni (SFT).
</Steps>

## Ce rulează în browser și ce rulează local

:::note[Pyodide în browser, PyTorch local]
Exemplele despre prelucrarea datelor rulează direct în pagină, cu Python rulat în WebAssembly (Pyodide). Ele folosesc un eșantion de 300 de povești și chiar fișierul `tokenizer.py` al laboratorului. Tot în browser putem încerca și calcule mici, de exemplu numărul de parametri, curba ratei de învățare sau eșantionarea.

Antrenarea propriu-zisă are nevoie de PyTorch și de câteva sute de megaocteți de date, așa că se face local. Paginile arată comenzile și rezultatele de referință, ca să puteți compara ușor ce obțineți local cu rezultatele din laborator.
:::

## Cerințe de sistem

- **Python** 3.10 sau mai nou.
- **Spațiu pe disc**: circa 1 GB pentru datele descărcate (circa 210 MB de text), fișierele cu tokenuri și modelele salvate pe parcurs (_checkpoints_).
- **Hardware**: codul alege singur cel mai rapid dispozitiv disponibil.
  - O placă grafică NVIDIA cu CUDA (varianta recomandată și cea mai rapidă).
  - Un cip Apple Silicon (M1 sau mai nou), prin MPS.
  - Procesorul obișnuit (CPU), mai lent, dar suficient pentru a parcurge toți pașii.
- **Timp estimat**: câteva minute pentru pregătirea datelor, plus 10 minute pentru preantrenare și 10 minute pentru ajustarea fină.

Pentru a urmări codul, sunt suficiente cunoștințele de bază de Python. [Rețelele neuronale](/retele-neuronale/ce-sunt-retelele-neuronale/) și [mecanismul de atenție](/modele-lingvistice/avem-nevoie-doar-de-atentie/) sunt explicate în secțiunile teoretice ale documentației.

## Pregătirea mediului de lucru

Puteți clona tot repozitoriul cu Git sau puteți descărca fișierele unul câte unul, cu `curl`.

<Tabs>
  <TabItem label="Git (recomandat)">
  ```bash
  git clone https://github.com/inteligentArtificiala-ro/laborator-lm-de-la-zero.git
  cd laborator-lm-de-la-zero

  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```
  </TabItem>
  <TabItem label="Descărcare cu curl">
  ```bash
  mkdir mvgpt && cd mvgpt
  for f in tokenizer.py data.py model.py checkpoint.py sample.py pretrain.py sft.py requirements.txt; do
    curl -fsSO "https://inteligentartificiala.ro/laboratoare/model-lingvistic-de-la-zero/cod/$f"
  done

  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```
  </TabItem>
</Tabs>

:::tip[PyTorch pentru plăci grafice NVIDIA]
Dacă folosiți o placă grafică NVIDIA, puteți alege de pe [pagina oficială PyTorch](https://pytorch.org/get-started/locally/) varianta potrivită pentru versiunea de CUDA instalată. Pe macOS (MPS) și pe CPU, varianta pe care o instalează implicit `pip` funcționează fără alte setări.
:::

Tot laboratorul se reduce la câteva comenzi, explicate pe paginile următoare.

```bash
python data.py                 # datele, vocabularul și fișierele cu tokenuri
python pretrain.py 10          # preantrenare timp de 10 minute
python sample.py checkpoints/pretrain/model.pt "Once upon a time"
python sft.py 10               # ajustare fină timp de 10 minute
python sample.py checkpoints/sft/model.pt "Words: dog, ball, happy. Story:"
tensorboard --logdir runs      # graficele antrenărilor, la http://localhost:6006
```
