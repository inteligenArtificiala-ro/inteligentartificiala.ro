Acesta este un glosar de termeni frecvent folosiți în inteligența artificială, învățarea automată și procesarea limbajului natural. Fiecare termen include explicația în română și echivalentul în engleză.

## A

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Acuratețe | Accuracy | Procentul de predicții corecte din totalul predicțiilor. |
| Afișarea textului pe măsura generării | Streaming | Tehnică prin care tokenurile apar pe ecran imediat ce sunt generate, fără să se aștepte răspunsul complet. |
| Ajustare fină | Fine-tuning | Antrenarea suplimentară a unui model preantrenat pe un set de date specific, pentru o sarcină anume. |
| Antrenare | Training | Procesul prin care un model învață din date, ajustându-și parametrii. |
| Arhitectură | Architecture | Structura generală a unui model de învățare automată (cum sunt conectați neuronii, câte straturi are etc.). |
| Atenție | Attention | Mecanism care permite modelului să se concentreze pe anumite părți ale intrării atunci când produce ieșirea. |
| Atenție încrucișată | Cross-Attention | Atenție în care interogările vin dintr-o secvență, iar cheile și valorile din alta, de exemplu din tokenurile textului care ghidează generarea unei imagini. |
| Atenție cu capete multiple (multi-head) | Multi-head Attention | Mecanism care rulează în paralel mai multe capete de atenție, fiecare cu propriile proiecții, pentru a surprinde tipuri diferite de dependențe. |
| Auto-atenție | Self-Attention | Atenție în care tokenurile unei secvențe se raportează unele la altele, folosită în Transformer pentru a surprinde dependențele dintre ele. |
| Autoencoder | Autoencoder | Rețea formată dintr-un codificator, care comprimă datele într-o reprezentare mai mică, și un decodor, care le reconstruiește din ea. |
| Autoencoder variațional (VAE) | Variational Autoencoder | Autoencoder care învață o reprezentare latentă continuă, folosit pentru a comprima imaginile și clipurile video înaintea difuziei latente. |
| Autoconsecvență | Self-Consistency | Metodă care generează mai multe lanțuri de gânduri pentru aceeași întrebare și păstrează răspunsul final cel mai frecvent (vot majoritar). |

## B

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Bază de date vectorială | Vector Database | Bază de date care stochează reprezentări vectoriale și găsește rapid vectorii cei mai apropiați de un vector dat. |
| _Bias_ | Bias | Parametru adăugat la suma ponderată a unui neuron, care deplasează valoarea primită de funcția de activare. |

## C

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Căutare pe fascicul | Beam Search | Strategie de decodare care păstrează la fiecare pas mai multe secvențe candidate, pentru a găsi o secvență cât mai probabilă. |
| Clonarea vocii | Voice Cloning | Generarea vorbirii cu vocea unei persoane anume, pornind de la o înregistrare scurtă a acelei voci. |
| Coborâre pe gradient | Gradient Descent | Metoda de optimizare care ajustează parametrii modelului în direcția opusă gradientului funcției de pierdere. |
| Codec audio neuronal | Neural Audio Codec | Autoencoder care comprimă sunetul într-un șir de tokenuri dintr-un vocabular fix și îl poate reconstrui din ele, de exemplu EnCodec. |
| Codificare pozițională | Positional Encoding | Informația despre poziția tokenurilor într-o secvență, adăugată la reprezentările vectoriale sau aplicată direct în calculul atenției. |
| Codificator de text | Text Encoder | Model care transformă un text într-un șir de vectori, folosit pentru a ghida generarea unei imagini, de exemplu CLIP sau T5. |
| Conexiune reziduală | Residual Connection | Legătură care adună intrarea unui bloc la ieșirea lui, astfel încât informația și gradienții să treacă direct peste straturi, ca în rețelele reziduale. |
| Convoluție | Convolution | Operație care aplică filtre pe date spațiale sau secvențiale (folosită în rețelele convoluționale, CNN). |
| Cuantizare | Quantization | Tehnică de reducere a mărimii modelului prin stocarea ponderilor cu mai puțini biți. |
| CUDA | CUDA | Platformă de calcul paralel dezvoltată de NVIDIA pentru plăcile sale grafice. |

## D

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| _Deepfake_ | Deepfake | Imagine, clip video sau înregistrare audio generată ori manipulată, care pare să arate o persoană, un loc sau un eveniment real. |
| Decodare speculativă | Speculative Decoding | Tehnică de accelerare a generării în care un model mic propune câteva tokenuri, iar modelul mare le verifică pe toate într-o singură trecere. |
| Derivată | Derivative | Rata de schimbare a unei funcții, folosită la calculul gradienților. |
| Diferențiere automată | Automatic Differentiation (autograd) | Calculul automat și exact al derivatelor unui program pe baza grafului computațional, oferit în PyTorch de `autograd`. |
| Difuzie latentă | Latent Diffusion | Model de difuzie care lucrează pe reprezentarea comprimată a unei imagini, produsă de un autoencoder, nu direct pe pixeli. |
| Dimensiune | Dimension | Numărul de valori dintr-un vector, de exemplu dintr-o reprezentare vectorială. |
| Dimensiunea lotului | Batch Size | Numărul de exemple dintr-un lot folosit la un pas de antrenare. |
| Distilare | Knowledge Distillation | Tehnică prin care un model mai mic este antrenat pe ieșirile unui model mai mare, ca să-i preia comportamentul. |

## E

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Eliminarea zgomotului | Denoising | Estimarea și îndepărtarea zgomotului dintr-o imagine sau dintr-un semnal, sarcina pe care o învață rețeaua unui model de difuzie. |
| Epocă | Epoch | O trecere completă prin întregul set de antrenare. |
| Eșantionare top-k | Top-k Sampling | Metodă de generare care alege următorul token doar dintre cele k tokenuri cele mai probabile. |
| Eșantionare top-p (nucleus) | Top-p (Nucleus) Sampling | Metodă de generare care alege următorul token doar din cel mai mic set de tokenuri a căror probabilitate cumulată atinge pragul p. |
| Evaluare | Evaluation | Testarea performanței modelului pe un set de date pe care nu l-a văzut la antrenare. |

## F

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Fereastră de context | Context Window | Numărul maxim de tokenuri pe care modelul le poate procesa la un moment dat. |
| Filigran digital | Watermark | Semnal ascuns într-o imagine, un sunet sau un clip generat, după care conținutul poate fi recunoscut ulterior ca generat, de exemplu SynthID. |
| Formă de undă | Waveform | Șirul de eșantioane care descrie un sunet în timp. |
| Funcția liniară rectificată (ReLU) | Rectified Linear Unit (ReLU) | Funcție de activare care întoarce 0 pentru valorile negative și valoarea însăși pentru cele pozitive, adică max(0, x). |
| Funcție de activare | Activation Function | Funcție neliniară aplicată la ieșirea unui neuron, care îi permite rețelei să învețe relații neliniare. |
| Funcție de pierdere | Loss Function | Funcția care măsoară cât de departe sunt predicțiile modelului de valorile corecte, iar valoarea ei se numește pierdere sau eroare. |

## G

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Generare augmentată prin regăsire (RAG) | Retrieval-Augmented Generation (RAG) | Metodă prin care sistemul caută documente relevante și le pune în contextul modelului înainte ca acesta să răspundă. |
| Ghidare fără clasificator | Classifier-Free Guidance (CFG) | Tehnică de generare care combină estimarea zgomotului făcută cu text și fără text, ca rezultatul să urmeze mai fidel descrierea. |
| Gradient | Gradient | Vectorul derivatelor parțiale, care indică direcția în care funcția de pierdere crește cel mai repede. |
| Gradienți care dispar | Vanishing Gradients | Problemă a rețelelor adânci în care gradienții devin foarte mici pe măsură ce sunt propagați înapoi, iar primele straturi aproape nu mai învață. |
| Gradienți care explodează | Exploding Gradients | Problemă a rețelelor adânci sau recurente în care gradienții devin foarte mari pe măsură ce sunt propagați înapoi, iar antrenarea devine instabilă. |
| Graf computațional | Computational Graph | Graf în care nodurile sunt operațiile unui calcul, iar muchiile duc valorile intermediare, folosit pentru calculul automat al gradienților. |
| GRPO | GRPO (Group Relative Policy Optimization) | Algoritm de învățare prin consolidare care compară mai multe răspunsuri la același prompt și le face mai probabile pe cele mai bune decât media grupului. |

| Hugging Face Hub | Hugging Face Hub | Platformă centralizată unde sunt publicate modele, seturi de date și tokenizatoare. |

## L

## M

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Mască | Mask | Vector sau matrice care indică ce tokenuri sunt vizibile și care trebuie ignorate. |
| Memorare | Memorization | Reproducerea aproape identică, de către un model generativ, a unor exemple din datele de antrenare. |
| Memoria agentului | Agent Memory | Mecanismele prin care un agent păstrează informații între pași sau sesiuni și le aduce înapoi în context când are nevoie de ele. |
| Memoria cache pentru chei și valori | KV Cache | Păstrarea cheilor și valorilor de atenție ale tokenurilor deja procesate, ca să nu fie recalculate la generarea fiecărui token nou. |
| Metrici | Metrics | Măsuri pentru evaluarea performanței unui model (precizie, sensibilitate, perplexitate etc.). |
| Model | Model | Funcția matematică, cu parametri învățați din date, care face predicții. |
| Model de difuzie | Diffusion Model | Model generativ care învață să elimine treptat zgomotul din date și generează date noi pornind de la zgomot pur. |
| Model de limbaj cauzal | Causal Language Model | Model care prezice următorul token dintr-o secvență pe baza tokenurilor anterioare, folosit la generarea de text. |
| Model de limbaj mare (LLM) | Large Language Model (LLM) | Model de limbaj cu miliarde de parametri, antrenat pe cantități foarte mari de text. |
| Model de raționament | Reasoning Model | Model de limbaj antrenat special să genereze un raționament lung înainte de răspunsul final. |
| Model salvat | Checkpoint | Fișier care salvează starea modelului (ponderile și starea optimizatorului) la un moment dat. |
| _Momentum_ | Momentum | Tehnică de optimizare care accelerează convergența prin păstrarea unei „inerții” din pașii anteriori. |

## P

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Parametru | Parameter | Valoare ajustabilă a modelului (o pondere sau un _bias_), învățată din date. |
| Perplexitate | Perplexity | Măsură a cât de bine prezice un model tokenurile unui text, la care valorile mai mici înseamnă predicții mai bune. |
| Petic | Patch | Bloc mic dintr-o imagine sau dintr-un clip video, tratat ca un singur token de un Transformer. |
| _Pipeline_ | Pipeline | În biblioteca Transformers, interfața simplificată care face automat tokenizarea, inferența și decodarea. |
| Placă grafică (GPU) | GPU (Graphics Processing Unit) | Hardware specializat în calcul paralel, folosit pentru a accelera antrenarea și inferența rețelelor neuronale. |
| Ponderi | Weights | Parametrii care stabilesc cât contează fiecare intrare pentru fiecare neuron. |
| Potrivirea fluxului | Flow Matching | Metodă înrudită cu difuzia, în care rețeaua învață direcția (viteza) care leagă zgomotul de date, de-a lungul unor drumuri aproape drepte. |
| Preantrenare | Pretraining | Prima etapă de antrenare, pe un corpus foarte mare de text, înainte de ajustarea fină. |
| Precizie | Precision | Proporția predicțiilor pozitive care sunt cu adevărat pozitive. |
| Program de zgomot | Noise Schedule | Regula după care crește cantitatea de zgomot de la un pas la altul în procesul direct al unui model de difuzie. |
| Prompt | Prompt | Textul de intrare dat unui model de limbaj pentru a genera o ieșire. |
| Prompt negativ | Negative Prompt | Descrierea a ceea ce nu trebuie să apară într-o imagine generată, folosită în locul textului gol la ghidarea fără clasificator. |
| Propagare directă | Forward Propagation (Forward Pass) | Calculul care trece datele prin rețea de la intrare spre ieșire, strat cu strat. |
| PyTorch | PyTorch | Bibliotecă open-source pentru învățare profundă, creată de Meta și administrată din 2022 de PyTorch Foundation. |

## R

| Termen (RO) | Termen (EN) | Explicație |
|-------------|-------------|------------|
| Rată de eșantionare | Sample Rate | Numărul de măsurători (eșantioane) pe secundă ale unui semnal audio, de exemplu 24.000 (24 kHz). |
| Rată de învățare | Learning Rate | Hiperparametrul care controlează mărimea actualizărilor parametrilor la fiecare pas. |
| Regula lanțului | Chain Rule | Regula din calculul diferențial după care derivata unei funcții compuse este produsul derivatelor funcțiilor care o compun. |
| Reprezentare latentă | Latent Representation | Forma comprimată a datelor produsă de codificatorul unui autoencoder, din care decodorul le poate reconstrui. |
| Reprezentare vectorială | Embedding | Vector dens care reprezintă un token, un cuvânt sau un text, astfel încât sensurile asemănătoare să aibă vectori apropiați. |
| Retropropagare | Backpropagation | Algoritmul care calculează eficient gradienții tuturor parametrilor, aplicând regula lanțului de la ieșire spre intrare. |
| Retropropagare în timp (BPTT) | Backpropagation Through Time | Retropropagarea aplicată unei rețele recurente desfășurate în timp, în care gradienții trec înapoi prin toți pașii secvenței. |
| Rețea feed-forward | Feed-forward Network | Componentă a unui bloc Transformer care aplică aceeași transformare neliniară fiecărei poziții, independent. |
| Rețea generativă adversarială (GAN) | Generative Adversarial Network | Pereche de rețele antrenate una împotriva celeilalte: una generează exemple, iar cealaltă încearcă să le deosebească de cele reale. |
| Rețea neuronală | Neural Network | Structură de neuroni artificiali interconectați, organizați în straturi, care învață reprezentări din date. |
| RLHF | RLHF (Reinforcement Learning from Human Feedback) | Învățare prin consolidare din feedback uman, o tehnică de aliniere în care modelul este optimizat după un model de recompensă antrenat pe preferințe umane. |
